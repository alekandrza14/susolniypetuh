Открой проверку из игры после выбора сертификата. Продолжить сможет зарегистрированный игрок с привязанным телефоном.

Игрок получит SMS-код. Для аккаунта владельца откроется вход по паролю без SMS.

Для защиты входа автор видит IP, браузер, время и это название. В браузере сохраняется случайный идентификатор. Журнал хранится до 30 дней.

На свой номер SMS отправлять не нужно.

Проверка телефона подтверждает доступ к учётной записи игрока. Списаний и покупок на этой странице нет.
